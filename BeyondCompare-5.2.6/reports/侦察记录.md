## 3. ★ 关键发现：Delphi RTTI 自带符号表

BC 是 Delphi VCL 应用，**编译时保留了 RTTI 字段名**，等于免费拿到结构体成员名。

### 3.1 许可 / 注册记录（`FRegInfo` 结构）

```
SerialNumber      ExpiryDate        Starts          Grace
Threshold         RegName           RegInfoArray
NewVersionAvail   NewVersionURL     InstPeriodStart  InstPeriodLength
TSPKDigest        TState
```

### 3.2 反篡改 / 校验相关

```
FAntiTamper       FRevokedSerials   FCheckProtCount   IntDigest
FCertificate      FASCIIEncoding    FLastError        FScanLastModPath
FExeName          FExeArch          FMessageFlags     FNow
```

> `FRevokedSerials` = **已吊销序列号列表**；`FAntiTamper` = 反篡改标志；`IntDigest` = 完整性摘要。

### 3.3 更新检查

```
FNewVersionAvail          ← ★ 更新可用标志（汇聚点候选）
FNewVersionURL            ← ★ 更新下载 URL
TCheckForUpdatesState     TCheckForUpdatesState2
DlgCheckForUpdates        ← ★ 更新对话框
CheckForUpdatesDayAmt     ← 检查间隔（天）
FDisabled  FLastChecked  FMsgDate  FMsgDaysDate  FRevoked
```
