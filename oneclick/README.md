# 一键安装

这里放的是每个软件的一键安装脚本。跑完会出现「完成」，并告诉你：装到哪、怎么打开、怎么删。

**最简单的用法**：直接双击上一级文件夹里的 `安装-XXX.cmd`。

**或者复制命令**：把下面表格里对应脚本组成的那一行命令，粘贴到管理员 PowerShell 里回车。

| 软件 | 干什么用的 | 脚本文件 | 双击启动器 |
| :--- | :--- | :--- | :--- |
| HexHub | 连服务器、传文件 | `hexhub.ps1` | `安装-HexHub.cmd` |
| Listary | 文件快速搜索 | `listary.ps1` | `安装-Listary.cmd` |
| Beyond Compare | 文件、文件夹对比 | `beyondcompare.ps1` | `安装-BeyondCompare.cmd` |
| Quicker | 快捷操作、效率工具 | `quicker.ps1` | `安装-Quicker.cmd` |
| 妙妙屋X | 服务器节点管理面板 | `miaomiaowux.ps1`（Windows）/ `miaomiaowux.sh`（Linux） | `安装-妙妙屋X.cmd` |

命令和详细说明见上层文件夹的 `README.md`，或各软件文件夹里的《使用说明.txt》。
