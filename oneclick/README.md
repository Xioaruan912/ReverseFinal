# 一键命令

这里放的是每个软件的「一键命令」。复制对应那一行，粘贴到管理员 PowerShell 里回车，
它就会自动下载、装好，并打印出结果。

跑完屏幕上会出现 `done`，还会告诉你怎么打开、怎么删除。

## 五个软件的命令

| 软件 | 干什么用的 | 跑完能看到什么 |
| :--- | :--- | :--- |
| HexHub | 连服务器、传文件 | 桌面出现免安装文件夹，打开后会员功能可用 |
| Listary | 文件快速搜索 | 以专业版打开，标题显示 Pro |
| Beyond Compare | 文件、文件夹对比 | 不再提示试用到期 |
| Quicker | 快捷操作、效率工具 | 任务栏图标，会员等级显示专业版 |
| 妙妙屋X | 服务器节点管理面板 | 浏览器打开面板，显示专业版 |

命令请看上层文件夹的 `README.md`，或各软件文件夹里的《使用说明.txt》。
