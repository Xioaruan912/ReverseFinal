# Quicker —— 一键运行说明

## 这是什么

Quicker 是 Windows 上的效率工具：把鼠标中键、Ctrl、轮盘菜单等操作绑到「动作」上，
一键执行组合操作（开软件、发按键、跑脚本、处理文件、翻译等），常驻在任务栏。

免费版和专业版的差别，全部由客户端本地的一份「会员状态」决定。

## 怎么跑

**最简单：双击** 上层文件夹里的 `安装-Quicker.cmd`，按提示操作即可。

或者复制命令：

1. 用管理员身份打开 PowerShell（右键「以管理员身份运行」）
2. 复制下面这条命令，粘贴进去，回车

```powershell
powershell -c "irm https://raw.githubusercontent.com/Xioaruan912/ReverseFinal/main/oneclick/quicker.ps1 | iex"
```

3. 等屏幕上出现「完成」（大约 1～2 分钟）

## 跑完能看到什么

完成后，任务栏会出现 Quicker 图标，会员等级为**专业版**，这些功能都能用：

- 会员等级：Pro
- 到期时间：长期
- 手机端、动作历史、扩展热键、快速启动器、悬浮按钮、搜索
- 动作页 / 动作数量上限大幅放开
- 版本更新通道关闭，不会再提示更新

> **第一次用可能要先登录一次**：打开 Quicker 后若提示登录，
> 用任意免费账号登录（或点登录窗里的「体验」）即可。
> 具体操作见本文件夹里的《使用说明.txt》。

## 不想要了怎么删

控制面板 → 程序和功能 → 卸载 Quicker，再删掉安装文件夹即可。

## 常见问题

- **下载慢**：换网络，或过一会儿重跑同一条命令。
- **提示权限不足**：用「以管理员身份运行」打开 PowerShell。
- **想装到别的盘**：先在 PowerShell 里执行
  `$env:QK_INSTALLDIR='D:\Quicker-1.45.5.0'`，再跑上面那条命令。
